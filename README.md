# Networkwalks W2 PM1 / PM4

A Week 2 cybersecurity practical report covering **footprinting, network scanning, and reconnaissance** activities completed during the Networkwalks internship program.

## Contents

- [`Cybersecurity final report.docx`](./Cybersecurity%20final%20report.docx) - detailed practical report with commands, findings, screenshots, and observations.
- [`READINESS.md`](./READINESS.md) - repository handoff and readiness status.

## Activities covered

The report documents work performed in Kali Linux using:

- WHOIS
- WhatWeb
- Nslookup
- cURL
- Wafw00f
- DNSRecon
- theHarvester

The activities cover public-information gathering, DNS and web technology identification, HTTP header inspection, WAF detection, DNS record enumeration, and email reconnaissance.

## Scope and authorization

The report states that testing was performed only against systems owned by the author or covered by written permission. The material is intended for education and authorized security research only. Do not apply these techniques to systems without explicit authorization.

## Status

The report identifies the reconnaissance and scanning phases as completed and later testing phases as in progress. This repository is a document-based submission; no software build, dependency installation, or automated test suite is required.
